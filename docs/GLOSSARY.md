# Glosario — BarberSchool

Terminología del dominio barbería y del proyecto. Actualizar al introducir nuevos conceptos.

---

## Dominio barbería

| Término | Definición |
|---------|------------|
| **Fade / Degradado** | Corte donde el cabello cambia gradualmente de largo a corto en los lados y la nuca |
| **Taper** | Degradado suave sin línea marcada; el cabello se acorta progresivamente hacia el cuello |
| **Buzz cut** | Corte uniforme a una sola longitud en todo el cráneo |
| **Line up** | Diseño y definición de líneas frontales, laterales y del cuello con trimmer o navaja |
| **Clipper** | Máquina de cortar cabello con peines de distintos números (#0–#8) |
| **Trimmer** | Máquina de detalle para contornos, líneas y acabados finos |
| **Guía** | Línea visible creada con un número de peine que sirve de referencia para fundir |
| **Fundir** | Técnica de mezclar dos longitudes para eliminar líneas visibles entre ellas |
| **Número de peine** | Altura de corte del clipper; #0 es la más corta (casi a piel) |
| **Contorno** | Zona lateral y posterior del corte, alrededor de orejas y nuca |

## Términos del producto

| Término | Definición |
|---------|------------|
| **Sesión de corte** | Instancia de un corte en progreso o completado; agrupa fotos, pasos y respuestas |
| **Flujo guiado** | Secuencia ordenada de pasos que el barbero sigue durante un corte |
| **Paso** | Unidad individual del flujo con título, descripción y orden |
| **Imagen de referencia** | Foto de ejemplo del corte objetivo que el barbero consulta mientras trabaja |
| **Tarjeta de decisión** | Pregunta de autoevaluación con opciones Sí / Parcial / No al finalizar el corte |
| **Tipo de corte** | Categoría predefinida (fade bajo, taper, buzz cut, etc.) con flujo y tarjetas asociados |
| **Historial** | Listado de sesiones pasadas con metadatos, fotos y resultados |

## Términos técnicos

| Término | Definición |
|---------|------------|
| **Offline-first** | Arquitectura donde la app funciona sin internet; datos solo en el dispositivo |
| **Expo** | Framework y plataforma para desarrollo React Native |
| **Expo Router** | Sistema de navegación file-based para Expo |
| **SQLite** | Base de datos relacional embebida para metadatos locales |
| **FileSystem** | Almacenamiento de archivos (fotos) en el directorio de la app |
| **Zustand** | Librería de estado global ligera para React |
| **ADR** | Architecture Decision Record — documento que registra una decisión técnica |
| **CI/CD** | Integración y despliegue continuos automatizados |
| **MVP** | Minimum Viable Product — versión mínima funcional del producto |
| **Front-matter** | Bloque YAML de metadatos al inicio de cada documento del kit |

## Estados del kit de documentación

| Término | Definición |
|---------|------------|
| **current** | Documento completo y alineado con el estado actual |
| **in_progress** | Documento en redacción o actualización activa |
| **planned** | Documento identificado pero sin contenido redactado |
| **outdated** | Documento que no refleja el estado actual del código |
| **aligned** | Sincronización: documento refleja fielmente el código |
| **partial** | Sincronización: documento parcialmente alineado |
